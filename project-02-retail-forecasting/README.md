# Project 02 — Retail Demand & Inventory Optimization

## Business question
How can we forecast product-store demand and identify where forecast errors create stockout or excess-inventory risk?

## Planned implementation
- Establish a seasonal-naive baseline before complex models.
- Use chronological train/validation/test splits to prevent time leakage.
- Report WMAPE and signed bias with defined denominators.
- Compare models by SKU/store and forecast horizon.
- Add inventory scenarios only when lead-time, service-level, and cost assumptions are explicit.

Use a public dataset only after verifying its terms and documenting its source. This is a planning scaffold; no model performance claims have been made.
